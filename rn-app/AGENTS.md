# AGENTS.md

## Project overview

**rn-app** is a React Native starter built with Expo SDK 57 (React Native 0.86.3, React 19.2.3), Expo Router (~57.0.24), NativeWind 4, and the React Compiler (enabled in `app.json`). The app is `rn-app`.

For the full feature, screen, and capability reference, read **`docs/project-overview.md`**. The design-system source of truth is **`docs/theme-system.md`**.

## Package manager

This project uses **pnpm**. Do not use npm or yarn.

**Expo rule — this matters more than anything else here:** versioned React Native / Expo packages must be installed with `npx expo install <pkg>` (or `pnpm dlx expo install <pkg>`), never bare `pnpm add`. Expo pins a specific compatible version of every native module per SDK; bare installs break that matrix. After any dependency change, verify with `pnpm dlx expo-doctor@latest`.

```bash
pnpm install
pnpm run dev
```

Available commands:

```bash
pnpm run dev              # expo start (Metro; QR for Expo Go, w for web)
pnpm run android          # expo run:android (native dev build; needs prebuild)
pnpm run ios              # expo run:ios (native dev build; needs prebuild)
pnpm run web              # expo start --web
pnpm run lint             # expo lint (ESLint, eslint-config-expo)
pnpm run lint:fix         # eslint . --fix
pnpm run format           # prettier --write .
pnpm run format:check     # prettier --check .
pnpm run typecheck        # tsc --noEmit
pnpm run doctor           # expo-doctor (21 project health checks)
pnpm run prebuild         # expo prebuild (generates android/ + ios/)
pnpm run prebuild:android # expo prebuild --platform android
pnpm run prebuild:ios     # expo prebuild --platform ios
pnpm run build:apk        # gradle assembleRelease (needs prebuild + .env keys)
pnpm run build:aab        # gradle bundleRelease (needs prebuild + .env keys)
pnpm run build:ios        # eas build -p ios (requires EAS CLI + account)
```

There is no automated test command. Run typecheck/lint/build commands only when the user explicitly requests that validation.

## Key systems

### Routing (`app/`)

Expo Router with file-based routes. The root layout mounts a `Stack` with `headerShown: false`, wraps navigation theming via `ThemeProvider` (imported from `expo-router/react-navigation` — do **not** import from `@react-navigation/*`; Expo Router forked it in SDK 56 and those imports are unsupported in app code), and a `PortalHost` from `@rn-primitives/portal` for overlays. New screens are new files in `app/` — nothing to register.

### Theme system (token-first)

Read **`docs/theme-system.md`** before styling anything. Typed tokens live in `lib/design-tokens/` and are mirrored into `tailwind.config.js` (`primitive.*` raw palettes, semantic `bg-*`/`text-*`/`border-*`/`action-*`/`feedback-*` utilities, `font-headline/body/label`). Light/dark values are CSS variables in `app/global.css` toggled by NativeWind's `useColorScheme` (class-based dark mode). Screens must use semantic tokens, never raw `primitive.*` colors. The navigation theme (`lib/theme.ts`) feeds React Navigation's background/text colors.

### UI primitives (`components/ui/`)

shadcn/ui-style components built on `@rn-primitives/*` (universal primitives for RN + web), `class-variance-authority`, and NativeWind classes. `components.json` configures the shadcn CLI for this setup. `TextClassContext` (in `ui/text`) propagates text styles down the tree.

### App config (`app.json`)

`experiments.typedRoutes` and `experiments.reactCompiler` are enabled; plugins: `expo-router`, `expo-splash-screen`, `expo-font`, `expo-status-bar`. App name/scheme/version come from here — do not hardcode elsewhere.

## Expo platform rules

- **CNG project:** `android/` and `ios/` directories are **generated, not committed** — create them with `pnpm run prebuild` when building natively (the `android`, `build:apk`, and `build:aab` scripts require `android/`); never hand-edit generated files — change `app.json`/plugins and re-run prebuild instead.
- **Expo Go only runs the latest SDK.** After a new SDK release, upgrade with `pnpm dlx expo install expo@^<new> --fix`, then `pnpm dlx expo-doctor@latest`.
- Generated files (`expo-env.d.ts`, `nativewind-env.d.ts`, `.expo/`) are not hand-edited.
- `pnpm-workspace.yaml` sets `nodeLinker: hoisted` — required for Metro resolution with pnpm; do not remove.
- Fonts declared in `tailwind.config.js` (`Manrope`, `Inter`) are **not loaded** yet — text renders with system fonts until `expo-font` loading is added.

## Code conventions

- TypeScript strict mode. Use precise types and avoid `any`.
- Use the `@/` import alias.
- Formatting via Prettier (double quotes, semicolons, `prettier-plugin-tailwindcss` class sorting): run `pnpm run format`, never hand-format.
- Avoid unnecessary dependencies; prefer Expo-maintained packages.
- Keep changes focused; do not refactor unrelated files.
- Use conventional commit prefixes such as `feat:`, `fix:`, `refactor:`, `docs:`, and `chore:`.
- Run `pnpm run typecheck` before claiming any type-related work is done.
