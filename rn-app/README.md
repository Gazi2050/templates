# rn-app

A React Native starter built with Expo SDK 57, React Native 0.86, NativeWind, and Expo Router.

See [docs/project-overview.md](docs/project-overview.md) for the full feature, component, and capability reference.

## Getting Started (Local Development)

1. **Clone the repository**

   ```bash
   git clone <your-repository-url>

   cd rn-app
   ```

2. **Install dependencies**

   Make sure you have [pnpm](https://pnpm.io/) installed. Then run:

   ```bash
   pnpm install
   ```

3. **Start the development server**

   ```bash
   pnpm run dev
   ```

✅ Scan the QR code with [Expo Go](https://expo.dev/go) (latest version) on your device, or press `w` to open web. The dev server also serves `http://localhost:8081`.
