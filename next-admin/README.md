# next-admin

A responsive admin dashboard built with Next.js 16, TypeScript, Tailwind CSS v4, and shadcn/ui.

See [docs/project-overview.md](docs/project-overview.md) for the full feature, component, and capability reference.

## Getting Started (Local Development)

1. **Clone the repository**

   ```bash
   git clone <your-repository-url>

   cd next-admin
   ```

2. **Install dependencies**

   Make sure you have [pnpm](https://pnpm.io/) installed. Then run:

   ```bash
   pnpm install
   ```

3. **Start the development server**

   ```bash
   pnpm run dev
   ```

✅ The app will be running at `http://localhost:3000`
